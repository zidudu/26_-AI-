# 2.0.0 이후 구현 및 검증 기록

사용자 지시(2026-09-28): 아카라이브 오류를 먼저 수정하고 다음 디시인사이드에 접근한다. 기존 원본 우선 설정·파일·채널 일시중지를 보존한다.

| 단계 | 구현 범위 | 완료 기준 | 상태 |
|---|---|---|---|
| 1.3.0 | 대기 미디어 전용 작업, 예약 공정성, 긴 파일 시간 제한, 대기 사유 | 새 글 수집과 독립적으로 고정 대기 ID를 처리, 취소/재개·재시도 테스트 및 실제 감소 확인 | 구현·실제 파일 복구 확인 |
| 1.3.1 | 실행별 신규/기존 처리량과 실패 요청 문맥, 재시작 복구 | 오류 글/요청 상태가 추적 가능하고, 중단 후 중복 없이 이어받음 | 구현·큐 테스트·실제 HTTP 206 확인 |
| 1.4.0 | 검색·읽기·미디어 탐색과 운영 화면 | 검색 조건/로컬 미디어/안전한 본문 렌더링 및 화면 동작 검증 | 기능 테스트 완료, 실행 화면 확인 대기 |
| 1.5.0 | 보관 무결성·백업 복원 검증 | 누락/해시 이상 탐지, 분리된 복원 위치에서 DB/파일 확인, 원본 유지 | 전수 무결성·표본 복원 확인 |
| 2.0.0 | 디시인사이드 어댑터·공통 운영, 회귀 및 실제 공개 페이지 검증 | 목록/본문/미디어/댓글의 지원 범위 명시, 실제 접근 및 통합 검증 | 서버 적용 완료. 이후 운영에서 발견한 댓글 오류는 2.2.0에서 수정 |
| 2.1.0 | 글·미디어 북마크 및 필터 | 독립 저장·해제, 검색·종류·채널 필터, 재시작 보존 | 서버 적용 완료 |
| 2.1.1 | 글 북마크의 전체 본문 미디어 표시 | 본문 순서·필터·페이지 이동, 기존 북마크 보존 | 서버 적용 완료 |
| 2.2.0 | 디시 댓글 오류 격리·지속 재시도·실행 요약 | 실제 no=0 응답 재현, 정상 댓글 보존, 재시도 UI, 운영 DB 업데이트 및 공개 응답 확인 | 서버 적용·댓글 복구·자동 수집 재개 확인 완료 |

다음 후보는 아카라이브 미디어 대기의 처리량·재시도 경과를 더 쉽게 확인하는 화면입니다. 누적 대기 수와 실제 실패, 원문에서 사라진 파일을 구분하며, 전체 대기 항목이 다운로드 가능하다고 가정하지 않습니다.

버전 번호만 올려 완료로 처리하지 않는다. 새 코드는 테스트와 제한된 실제 검증 후 적용한다. 사용자 조작이 필요한 서버 재시작은 가능한 한 최종 통합 적용 시 한 번 요청한다. 접근 제한/로그인은 우회하지 않고 분류한다.

기준 백업: `data/backups/v2-development-baseline`. 미디어와 로그인 프로필은 변경·삭제하지 않는다.

통합 코드 2.0.0: 테스트 115개 통과, 컴파일 통과. 세부 수치와 한계는 [검증 보고서](RELEASE_V2.0.0.md) 참고.
