# 2.2.0 댓글 복구 및 실행 요약

2026-09-28. 현재 단계: 서버 2.2.0 적용 및 운영 댓글 복구 확인 완료.

## 확인한 문제와 수정

운영 실행 #173이 디시 글 385884 댓글 처리 중 `ValueError: Invalid DC item ID`로 중단됐습니다. 보관 응답에는 정상 댓글 5개와 `no=0`인 부가 행이 함께 있었고, 이전 파서는 이 행까지 댓글로 변환했습니다. 보관 응답으로 같은 예외를 재현했습니다.

- 번호 0 부가 행을 제외하고, 잘못된 번호·상위 번호·본문 형식은 행 단위로 기록합니다. 정상 댓글과 다음 글 수집을 계속합니다. 접근 제한이나 저장소 장애는 숨기지 않고 실행을 중단합니다.
- 댓글 저장이 끝난 뒤에만 저장 수를 증가시킵니다. 중복 페이지를 여러 번 저장 수에 포함하지 않습니다. 원본 JSON 보관 실패는 별도 경고를 남기고 댓글 DB 저장을 계속합니다.
- `comment_fetches`에 마지막 응답 개수, 저장 개수, 상태, 시도 횟수, 재시도 가능 시각을 기록합니다. 본문 수집 완료와 댓글 완료를 구분하며, 재시작 후에도 남습니다.
- 미완료 댓글은 재확인 예산 일부를 배정해 오래된 글도 재시도합니다. 지수 백오프와 최대 시도 횟수를 따릅니다. 오류 탭·게시글의 `댓글 재시도 예약`은 본문·미디어·북마크를 초기화하지 않습니다.
- 실행 기록은 실제 실패와 시간·개수 제한에 따른 이월을 구분합니다. 종료 시 측정할 미완료 수를 실행 중 0으로 표시하지 않습니다. 내부 오류 이벤트에 해당 글·미디어 ID를 남깁니다.

## 검증

- 자동 테스트: 전체 147개 통과 후, 재시도 한도·백오프 회귀 2개를 추가하여 댓글·웹 관련 35개 재검증 통과(총 149개 시나리오). 기존 테스트 도구의 deprecation 경고 2건은 남아 있습니다.
- 운영 DB 복사본: 스키마 6→7, 기존 10개 테이블의 모든 행 해시 동일, 북마크 18개 유지, SQLite quick_check 및 외래 키 검사 통과. 개수 확인이 필요한 디시 글 2개만 확인 대기로 등록됐습니다.
- 과거 응답 재생: 정상 댓글 5개 보관, 완료 상태 확인.
- 현재 공개 응답: 격리 DB에서 385884(9개), 385846(5개), 385885(3개) 총 17개 댓글 보관, 응답 개수와 일치. 이 격리 검증과 별도로 아래 운영 복구를 수행했습니다.
- 운영 복구 #182(14:05 KST): 자동 수집 중지·실행 잠금·적용 전 DB 백업 후, 385884 댓글 0→9개, 385846 댓글 1→5개로 복구. 기록된 미완료 댓글 항목 0개, 스키마 7. 본문 16,159행·미디어 42,262행·북마크 18행·채널 5행은 전후 전체 행 해시 동일. 기존 본문에 남은 댓글 개수는 당시 수집 시점 값이며, 새 댓글 상태에는 이번 응답 개수를 따로 표시합니다. 이 복구가 전체 채널 수집 완료를 뜻하지는 않습니다.
- Chrome/Playwright: 격리 TestClient 응답으로 PC 1440×1000, 모바일 390×844에서 오류→댓글 재시도→게시글, 실행 요약→상세 통계→이벤트 필터 확인. 콘솔/페이지 오류 없음. 서버 시작 명령 없이 검사했습니다.

기준 백업: `data/backups/development-20260928-134207/before.sqlite3` 및 `source-before.zip`. 운영 복구 직전 DB는 같은 폴더의 `before-apply.sqlite3`입니다.

## 범위와 남은 작업

댓글 완료는 마지막 공개 응답을 기준으로 판단합니다. 이후 추가·삭제된 댓글, 비공개 댓글까지 보장하지 않습니다. 현재 지원 검증 범위는 공개 디시 마이너 갤러리 aichatting입니다. 아카라이브 미디어 대기 전체가 복구됐다는 의미는 아닙니다.

14:52~14:53 KST 적용 확인: 웹 런타임 2.2.0, 스키마 7, 오류·실행·북마크·복구 글 2개의 화면 HTTP 200 및 댓글 확인 완료 표시. 기존 북마크 18개 전부 유지되고 현재 24개이며, bluearchive 비활성도 유지됩니다. 자동 수집은 켜져 있고 #183 ailove 수집이 진행 중입니다. aiart pending 14,267개는 별도의 미해결 미디어 대기 작업입니다. 이전 자동 승인 검토에서 서버 프로세스 종료·시작이 거절되어, 같은 명령을 재시도하거나 다른 도구로 우회하지 않습니다.
