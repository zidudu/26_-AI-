## 대기 수치의 의미

05:10 KST 고정 집단 기준: 미완료 16,828개 → **16,815개**. 같은 ID 집단에서 다운로드 완료로 바뀐 13개만 복구로 집계했다. 그 사이 새로 수집된 파일을 감소량으로 섞지 않았다. 이전 대화의 15,052개와 현재 총량은 측정 시점이 다르고 신규 글 유입이 있어 직접 감소율로 비교할 수 없다.

당시 16,815개 중 채널 일시중지 11, 원문 삭제 64, 주소 재확인 필요 14,977, 다음 작업 대상 1,762, 재시도 예약 1이었다. 이 분류는 저장된 근거이며 모든 URL의 다운로드 가능 여부를 실시간 검사한 결과가 아니다. 비활성 `bluearchive`를 활성화하거나 파일을 삭제해 수치를 줄이지 않았다.

기본 전용 작업은 15분 간격·10분 예산·글당 8개다. 단일 워커이므로 실행 중인 다른 작업을 선점하지 않는다. 가장 오래 기한을 넘긴 작업이 먼저 실행된다. 다운로드 가능 파일도 유입량·전송 속도에 따라 대기할 수 있다.

## 이어받기와 오류 기록

- `data/partials/`에 부분 파일을 보관한다. ETag/Last-Modified, Content-Range, 크기, 부분 파일 SHA-256을 확인한다.
- 파일이 바뀌었거나 Range를 지원하지 않으면 전체 응답으로 다시 시작한다. 잘못된 범위나 크기 불일치는 완료로 기록하지 않는다.
- 시간 제한으로 진행된 부분 수신은 일반 실패 횟수를 소모하지 않는다. 실제 완료 파일만 미디어 완료 수에 더한다.
- 시간 한도 확인은 64 KiB 청크 경계이며, 네트워크 읽기 대기는 별도 타임아웃의 영향을 받는다. 모든 외부 서버에서 이어받기를 보장하지 않는다.
- 미디어 응답/시간/바이트·글 ID·미디어 ID를 기록하며 서명 URL 쿼리와 로그인 쿠키는 이벤트에 남기지 않는다.
- 본문에서 사라진 미수집 참조는 `SOURCE_NOT_PRESENT`로 남기며 기존 파일과 참조를 보존한다. 반복 거부된 파일도 재시도 한도를 적용한다.

## 디시 지원 범위

실제 대상: [AI 채팅 마이너 갤러리](https://gall.dcinside.com/mgallery/board/lists/?id=aichatting). 정상 HTTP로 공개 목록과 본문을 읽고, 사이트의 실제 `comment.js`와 동일한 댓글 조회 요청을 사용했다. 쓰기·추천·댓글 등록 요청은 하지 않았다.

글 번호와 댓글 번호는 `채널 ID × 10^12 + 원격 번호`로 분리한다. 쿼리로 구분되는 두 이미지를 같은 파일로 합치지 않는다. 디시 이미지에 아카라이브의 `type=orig`를 임의로 붙이지 않으며 원본 여부는 미확인이다.

직접 `<video>` 참조는 파서/저장 경로를 지원하지만 이번 실제 검증 파일 4개는 이미지다. 외부 플레이어, 음성 댓글, 디시콘 파일, 일반/미니 갤러리의 완전한 보존은 검증 범위 밖이다. 댓글 조회 실패·페이지 상한은 부분 완료로 표시한다. 연도가 없는 댓글 날짜는 추측하지 않는다.

## 보관과 운영 한계

전체 해시 검사는 파일이 DB에 기록된 해시와 일치함을 뜻하며 업로더 원본과 동일함을 증명하지 않는다. 독립 복원 시험은 전체 DB와 파일 표본 10개만 포함했다. 전체 파일 복사 기능은 테스트됐지만 현재 보관 파일 25,182개를 전부 복사한 실증은 하지 않았다.

작업 중 기존 서버가 사라진 상태를 확인했다. Python 서버 프로세스와 8766 리스너가 없었고 마지막 작업 로그 뒤 종료 원인이 없었다. 확인한 Windows Application 이벤트에서도 관련 충돌 근거를 얻지 못했다. 원인은 미확인이다. 새 버전은 시작/정상 종료·Uvicorn 오류·Python 치명적 오류 기록과 큐 복구를 추가했지만 강제 종료 원인이 항상 기록되는 것은 아니다.
