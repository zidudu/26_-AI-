# 2.2.1 미디어 대기 처리량과 451 분류

2026-09-29. `aiart`의 누적 미디어 대기를 줄이고 접근 제한 항목을 만료 URL과 구분하기 위한 변경입니다.

- `aiart` 대기 전용 작업은 20분·글당 16개로 설정했습니다. 다른 채널은 기존 기본값 10분·8개를 유지합니다. 원본 우선 다운로드도 유지합니다.
- 기존 글을 다시 열 때 HTTP 451이 나오면 본문과 미디어 참조를 보존하고 글에 `BLOCKED_451` 및 다음 재확인 시각을 기록합니다. 같은 브라우저 세션의 로그인 상태가 확인되면 해당 글만 건너뛰고 다음 글을 처리합니다. 확인되지 않으면 실행을 중단합니다. 시각이 되면 다시 시도하며, 대기 진단 화면은 이를 별도 원인으로 집계합니다.
- 미디어 화면에 대기 원인 진단 링크를 추가했습니다.

변경 전 측정: `aiart` 대기 14,216개 중 저장된 URL 만료 분류 14,121개(2026-09-29 00:33 KST). 최근 10분 대기 작업 #178/#185/#191은 각각 24/20/25개를 복구했고 파일 요청에 약 594초를 사용했습니다. 이 분류와 표본은 전체 파일의 실제 다운로드 가능 여부를 보장하지 않습니다.

적용 후에는 451 기록 수, `aiart`의 기존 파일 다운로드 수/시간, 신규 생성 수, 대기 순증감을 24시간 관찰해야 합니다. 처리량 향상은 아직 운영 측정 전입니다. 서버 재시작 후 새 런타임에 적용됩니다.
