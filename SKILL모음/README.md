## 사용 방법

1. 위 목록에서 필요한 분야를 선택합니다.
2. 해당 묶음의 목록에서 사용할 스킬의 `SKILL.md`를 엽니다.
3. 사용하는 에이전트 도구의 등록 방식에 따라 스킬 폴더 전체를 등록하거나, 폴더 위치와 수행할 작업을 함께 전달합니다.
4. 실행 코드가 있는 스킬은 안내된 입력 형식과 의존성을 확인한 뒤 실행합니다.

개별 스킬은 핵심 지침인 `SKILL.md`와 필요한 참고자료·스크립트·보조 자료로 구성됩니다. 모든 스킬에 실행 코드가 있는 것은 아니며, 저장소를 내려받는 것만으로 자동 설치되지는 않습니다. 필요한 다른 스킬이나 외부 프로그램이 있다면 해당 스킬의 지침을 확인하세요.
