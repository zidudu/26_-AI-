## 실제 검증이 남은 항목

- Length Custom의 현재 범위와 길이 준수도.
- Variety, Weirdness, Style Influence의 상호작용.
- Personalization 토글의 실제 적용 단계와 결과 차이.
- 자유형 [] 지시, 악기 제한, 반복 모티프의 재현성.
- Cover·부분 편집의 원본 보존 정도와 연결부 품질.
- 일반 완곡과 Sounds Loop의 실제 반복 연결 품질.

향후 실험은 입력·모델·설정·결과를 기록하고 핵심 변수 하나씩 비교한다.
현재 추천과 사용자 선호를 실제 반복 검증된 성능으로 표시하지 않는다.
