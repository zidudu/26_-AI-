# github-deep-search

GitHub를 우선적으로 탐색해 오픈소스 프로젝트, 실제 코드 구현, 예제, 이슈와 변경 이력을 조사하는 범용 검색 스킬입니다.

## 특징

- 고정된 검색 절차를 강제하지 않음
- GitHub Repository + Code Search 중심
- 필요할 때 Issues / PR / Commits까지 확장
- 공식 문서와 웹 검색으로 교차 검증 가능
- 실제 오픈소스 재사용 시 라이선스와 호환성 확인
- 사용자 프로젝트가 제공되면 실제 통합까지 이어질 수 있도록 설계

핵심 파일은 `SKILL.md`입니다.
