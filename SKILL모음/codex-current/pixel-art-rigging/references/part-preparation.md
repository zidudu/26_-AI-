# 파츠 준비와 시각 검수

## 원본과 분리

사용자가 준 경로를 먼저 확인하고 실제 그림을 봅니다. 스크린샷, 미리보기, 파츠, 스프라이트 시트가 섞이면 각각의 역할을 구별합니다. 여러 파일 중 선택이 불명확하면 필요한 선택만 확인합니다.

레이어가 있으면 각 레이어의 원본 캔버스 좌표를 함께 내보냅니다. 잘라낸 PNG의 왼쪽 위 좌표를 `position`에 기록합니다. 파츠가 모두 전체 캔버스 크기라면 `[0,0]`을 쓰되 실제 투명 배경과 겹침을 확인합니다. 불투명 배경이 붙은 사각형을 옷이나 몸 파츠로 취급하지 않습니다.

단일 그림은 움직임에 필요한 만큼 의미 단위로 나눕니다. 예를 들어 머리와 얼굴, 앞/뒤 머리카락, 몸통, 상완/전완/손, 허리와 치마 앞/뒤, 다리/발, 장식입니다. 파츠 개수 자체를 목표로 하지 않습니다. 가려진 몸과 관절에 겹침 여유가 있어야 움직일 때 구멍이 나지 않습니다.

그림 편집과 가려진 부분을 그리는 작업은 사용 가능한 이미지 편집 도구 규칙을 따릅니다. 생성형 편집에는 팔레트·도트 배율·윤곽·특징을 보존하도록 지시하고 반환된 결과를 직접 검사합니다. 이를 픽셀 완전 보존이라고 주장하지 않습니다. 사용자가 명시적으로 코드나 특정 편집기를 통한 수정을 요청했다면 그 방법을 따릅니다. 편집 도구가 없으면 숨겨진 부분이 필요 없는 제한된 모션이나 준비된 파츠를 활용하되 한계를 밝힙니다.

앞뒤 순서대로 합성하고 기준 이미지와 비교합니다. 기존 파츠 추출은 차이 픽셀 수와 최대 오차를 확인합니다. 가려진 부분 복원 등 의도된 변경은 변경 영역과 이유를 설명합니다.

## 도트 격자와 모션

- 프레임은 원본 논리 해상도에서 렌더합니다. 확대는 정수 배율과 최근접 보간을 사용합니다.
- 알파 마스크는 실제 실루엣을 따릅니다. 0/255 알파 파츠는 최근접 변환에서도 중간 알파를 만들지 않습니다. 원본 반투명 픽셀은 임의로 제거하지 않습니다.
- 낮은 해상도의 회전은 계단 모양 변화가 생깁니다. 무조건 흐리게 하지 말고 회전각, 축 위치, 출력 크기, 일부 수작업 프레임 중 적합한 방법을 선택합니다.
- 부모·자식은 같은 기준 좌표계를 사용합니다. 몸통 이동을 자식에게 다시 더하면 이중 이동이 됩니다.
- 접지된 발이나 붙잡는 손을 고정하려면 독립 기준점과 실제 상·하위 팔다리 파츠를 사용합니다. 하나로 합쳐진 팔다리가 IK만으로 자연스럽게 휘어지지 않습니다.
- 루프는 시간 `[0,1)`로 렌더하고 곡선 0과 1 상태를 맞춥니다. 마지막 저장 프레임과 첫 프레임이 같을 필요는 없지만 경계의 이동이 주변 이동과 이어져야 합니다.

## 관찰할 지점

기준 자세, 좌우 최대 변형, 중간 자세, 마지막→첫 프레임을 봅니다. 머리·어깨·팔꿈치·손목의 틈, 앞머리와 얼굴 가림, 치마/다리 순서, 발의 미끄러짐, 천의 사각형 경계, 잘림, 팔레트 깜빡임을 확인합니다.

전체 알파 픽셀 수가 변했다는 이유만으로 구멍이라고 단정하지 않습니다. 회전과 겹침으로 면적은 변합니다. 파츠별 움직임과 기준 실루엣, 문제 위치를 함께 봅니다. 숫자 검증은 자연스러운 모션의 증거를 대신하지 않습니다.
