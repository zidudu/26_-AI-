# V10 10.0.0-rc1.6 — Codex 직접 로그인과 네이버 로그인 안내

## 요청과 확인한 기존 동작

2026-09-30 사용자 화면에서 Codex의 ‘로그인 방식 보기’는 터미널 명령을 안내하는 모달만 표시했습니다. 코드에서도 실제 로그인 실행 API가 없고, ‘로컬 Codex 로그인 연결 전’은 고정 문구였습니다. 사용자는 버튼에서 `codex login`을 실행하고, 네이버 로그인에는 가운데 순서 안내·로그인했습니다·취소·이미 로그인한 경우 재확인 기능을 요청했습니다.

## 변경

### Codex

- 기존 버튼을 ‘Codex 로그인’으로 변경하고 ‘상태 확인’을 추가했습니다.
- 로그인은 기존 AI 엔진과 같은 명령 해석 함수·설정 파일·인증 저장 옵션·사용자 환경을 사용합니다. npm 설치의 cmd 래퍼는 기존 어댑터 규칙대로 node.exe + codex.js로 해석합니다. shell 명령 문자열은 실행하지 않습니다.
- 버튼을 누르면 별도 Windows 콘솔에서 공식 로그인 명령이 실행됩니다. 브라우저가 자동으로 열리지 않으면 해당 콘솔의 공식 로그인 링크를 사용할 수 있습니다.
- 로그인 프로세스가 성공 종료한 뒤 `codex login status`에서 ChatGPT 방식을 확인한 경우만 초록색으로 표시합니다. API 키 방식·취소·실패·확인 오류는 성공 처리하지 않습니다.
- 초기 화면은 상태만 자동 확인합니다. 로그인 브라우저는 버튼으로 시작합니다. ‘상태 확인’은 AI 추론을 요청하지 않습니다.
- 중복 클릭 시 한 개 로그인 작업만 실행합니다. 로그인 진행 중 전체 실행을 시작하지 않으며, 수집/분석 실행 중에는 계정 변경을 막습니다.
- 10분 대기 제한이 있고 정상 서버 종료 시 자체 로그인 프로세스를 정리합니다. 인증 상태는 서버 메모리에서 관리하며 토큰·계정 비밀번호·CLI 원본 출력은 DB/HTTP 상태/작업 로그에 넣지 않습니다.

### 네이버

- 버튼을 누르면 가운데 안내창에 ‘로그인 → 세션 저장 확인 → 전용 Chrome 닫기 → 로그인했습니다’ 순서를 표시합니다. V10 화면과 서버 실행 창은 닫지 않도록 강조했습니다.
- 저장된 로그인 상태가 있으면 먼저 ‘이미 로그인되어 있습니다. 다시 로그인하시겠습니까?’와 ‘다시 로그인 / 취소’를 표시합니다. 서버도 명시적 확인 전에는 새 창을 실행하지 않습니다.
- ‘로그인했습니다’는 전용 Chrome의 종료와 서버의 세션 저장 상태를 확인합니다. 버튼 클릭만으로 인증 성공 상태를 만들지 않습니다. 네이버 서버에서의 실제 카페 접근 확인은 기존 수집 경로가 계속 담당합니다.
- 안내 중 취소는 전용 로그인 작업에 종료를 요청합니다. 보통 다음 로그인 확인 주기에서 닫히며, 페이지 이동 중이면 그 이동이 끝날 때까지 기다릴 수 있습니다. 다른 수집 작업은 종료하지 않습니다.
- 재로그인 질문에서 취소하면 기존 로그인 세션을 유지합니다. 로그인 취소는 네이버 로그아웃이나 저장 인증 삭제 기능이 아닙니다.
- 안내창의 Esc/닫기 버튼도 취소 흐름을 사용하며, 키보드 초점을 모달 내부로 제한합니다.

## 검증 범위

- Linux / Python 3.12: 74개 중 73개 통과, Windows DPAPI 1개 건너뜀.
- JavaScript 로직/API 계약: 49개 통과. 문법·Python 컴파일 통과.
- 기존 engine/ 파일 바이트는 RC1.5와 같습니다.
- Codex 프로세스 검사는 실제 자식 프로세스로 실행하는 로컬 CLI 대역을 사용했습니다. 실제 Windows 콘솔·OpenAI 로그인 브라우저·AI 응답 검증은 아닙니다.
- 네이버 신규 UI/취소 검사는 브라우저 대역과 HTTP/JavaScript로 수행했습니다. 실제 화면 렌더링·사용자 Windows 조작은 배포 후 확인 대상입니다.
- 사용자 RC1.5 Windows 검사는 59개 전부 통과했고, 실제 수집 이력에서 9개 카페 완료·14건을 확인했습니다. 이 확인은 RC1.6 로그인 UI의 실기기 검증을 대신하지 않습니다.

## 적용

1. 진행 중인 작업이 끝난 뒤 전용 로그인 창과 V10 실행 콘솔을 닫습니다.
2. ZIP 안 naver_cafe_v10 파일을 기존 폴더에 덮어씁니다. data_v10과 .venv는 유지합니다.
3. 03_verify_v10.bat의 RC1.6 / expected tests: 74 / OK를 확인합니다.
4. 02_start_v10.bat 실행 후 Ctrl+F5로 새로고침합니다.
5. Codex 상태가 이미 초록색이면 기존 인증을 그대로 사용합니다. 로그인이 필요하면 ‘Codex 로그인’을 누르고 공식 브라우저에서 인증합니다.
6. 네이버 로그인 버튼의 재로그인 질문·가운데 안내·전용 Chrome 종료 후 ‘로그인했습니다’를 확인합니다.

요구 패키지는 기존 requirements.txt에 포함되어 있습니다. 새 별도 의존성은 추가하지 않았습니다.
