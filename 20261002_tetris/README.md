# Drop Stack · 테트리스 방식 블록 퍼즐

브라우저에서 바로 실행하는 **테트리스 방식 낙하 블록 퍼즐**입니다. 설치·서버·빌드 없이 `index.html` 파일 하나로 동작합니다.

> 이름은 "테트리스" 상표를 피하려고 **Drop Stack**으로 지었습니다. 규칙은 현대 테트리스 가이드라인(SRS 회전, 7-bag, 홀드 등)을 따릅니다.

## 실행

- `index.html`을 Chrome·Edge·Firefox·Safari 등 브라우저로 엽니다.
- 인터넷이 없으면 Google Fonts 대신 시스템 글꼴로 표시될 뿐, 게임은 그대로 동작합니다.
- 최고 점수는 브라우저 `localStorage`(`drop-stack:best`)에 저장됩니다. 브라우저·기기마다 따로 기록됩니다.

## 조작

| 동작 | 키보드 | 터치(휴대폰) |
| --- | --- | --- |
| 좌우 이동 | `←` `→` (누르고 있으면 자동 반복) | 판을 좌우로 끌기 · `←` `→` 버튼 |
| 소프트 드롭 | `↓` | 판을 아래로 천천히 끌기 · `↓` 버튼 |
| 하드 드롭 | `Space` | 판을 아래로 튕기기 · `⤓` 버튼 |
| 시계 방향 회전 | `↑` 또는 `X` | 판을 탭 · `↻` 버튼 |
| 반시계 회전 | `Z` | `↺` 버튼 |
| 홀드 | `C` 또는 `Shift` | 판을 위로 튕기기 · `홀드` 버튼 |
| 일시정지/계속 | `P` 또는 `Esc` | 오른쪽 위 `Ⅱ` 버튼 |
| 시작 | `Enter` (시작 화면에서 `←` `→`로 시작 레벨 1~15 선택) | `게임 시작` 버튼 |
| 새 게임 | 일시정지·게임 오버 화면에서 `R` | 화면 버튼 |

창이 포커스를 잃거나 탭이 숨겨지면 자동으로 일시정지합니다.

## 구현한 규칙

| 항목 | 내용 |
| --- | --- |
| 판 | 가로 10 × 세로 20(보이는 영역) + 위쪽 숨은 2줄 |
| 회전 | SRS(Super Rotation System) — I 블록과 나머지 블록의 월킥 표를 각각 적용 |
| 블록 순서 | 7-bag(7종을 한 묶음으로 섞어 차례로 지급) · 다음 블록 5개 미리보기 |
| 보조 기능 | 홀드(블록 1개당 1회), 고스트(낙하 위치 표시) |
| 고정 지연 | 바닥에 닿은 뒤 0.5초. 이동·회전 시 초기화, 최대 15회(더 낮은 줄에 닿으면 횟수 초기화) |
| 자동 반복 | DAS 167ms, ARR 33ms |
| 낙하 속도 | 가이드라인 공식 `(0.8 − (레벨−1) × 0.007)^(레벨−1)`초/줄, 레벨 20에서 상한 |
| 레벨 | 10줄마다 1 상승(시작 레벨 + 지운 줄 ÷ 10) |
| 게임 오버 | 새 블록이 나올 자리가 막히거나, 블록이 전부 숨은 줄에 고정될 때 |

### 점수 (× 현재 레벨)

| 동작 | 점수 |
| --- | --- |
| 1 / 2 / 3 / 4줄 | 100 / 300 / 500 / 800 |
| T-스핀 (줄 없음 / 1 / 2 / 3줄) | 400 / 800 / 1,200 / 1,600 |
| T-스핀 미니 (줄 없음 / 1 / 2줄) | 100 / 200 / 400 |
| 백투백(4줄·T-스핀 줄 지우기 연속) | 해당 점수 × 1.5 |
| 콤보 | 50 × 콤보 수 |
| 퍼펙트 클리어(판 전체 비움) 추가 | 1 / 2 / 3 / 4줄 기준 800 / 1,200 / 1,800 / 2,000 |
| 소프트 드롭 / 하드 드롭 | 1칸당 1 / 2 (레벨 무관) |

T-스핀은 **3-코너 규칙**으로 판정합니다. 마지막 동작이 회전이고 T 중심의 대각선 네 칸 중 세 칸 이상이 막혀 있으면 T-스핀이며, T가 향한 쪽 두 칸이 모두 막혔거나 마지막 월킥(5번째 시도)으로 들어갔으면 정식, 아니면 미니입니다.

## 화면 구성

- **왼쪽**: 홀드, 점수·최고·레벨·지운 줄, 키보드 조작표
- **가운데**: 게임 판. 위쪽 4줄까지 쌓이면 테두리가 빨갛게 바뀝니다.
- **오른쪽**: 다음 블록 5개, 기록(시간, 초당 블록 수 PPS, 4줄 비율, 최대 콤보), 블록 종류별 분포
- **휴대폰(가로 620px 미만)**: 점수가 판 위 한 줄로 올라가고, 터치 기기에서는 판 아래에 조작 버튼이 나타납니다. 판 크기는 화면 높이·너비에 맞춰 자동 조절됩니다.

## 검증 기록 (2026-10-02, Linux · Playwright Chromium headless)

자동 검사 27개 통과.

- 데스크톱(1280×820): 시작 화면 → `Enter` 시작, `←`/`→` 시작 레벨 선택, 왼쪽 키 누르고 있기(DAS)로 벽까지 이동, `↑` 회전, `C` 홀드와 같은 턴 재홀드 차단, `Space` 하드 드롭 점수, `P` 일시정지/계속, 하드 드롭만 반복 시 게임 오버, 최고 점수 저장
- T-스핀 더블 시나리오: 미리 만든 판에서 T를 회전·소프트 드롭·회전으로 넣었을 때 2줄 삭제, 1,200 + 소프트 드롭 2 = **1,202점**, 줄 삭제 후 다음 블록 등장 확인
- 휴대폰(iPhone 13 에뮬레이션): 가로 넘침 없음, 터치 버튼 표시, 판 탭 회전, 버튼 이동·하드 드롭, 조작 버튼까지 한 화면(664px)에 들어감

**확인하지 않은 것**: 실제 휴대폰 기기에서의 조작감, Safari·Firefox 실기 동작, 장시간 플레이. 효과음·180도 회전·온라인 순위는 없습니다.
