# Chrome 확장 프로그램

이 폴더는 PC의 YouTube Media Library 서버와 연결되는 Chrome 확장 프로그램입니다.
현재 탭이 YouTube 영상·Shorts·라이브·일반 재생목록이면 도구 모음 버튼에서
`수집 창에 보내기`를 누르세요. 라이브러리의 수집 창에 주소가 채워집니다.
로그인이 필요한 경우 로그인 후 같은 수집 창으로 이어집니다.
저장 항목과 화질을 확인한 뒤 `대기열에 추가`를 누르면 PC 서버가 작업합니다.

현재 탭을 읽지 못하거나 나중에 받은 링크를 넣고 싶다면 팝업의
**링크 직접 넣기** 칸에 HTTPS YouTube 영상·Shorts·라이브 또는 일반 재생목록
주소 하나를 붙여 넣고 **링크로 수집 창 열기**를 누르세요. 잘못된 주소는
팝업에서 안내합니다. 여러 링크를 한꺼번에 넣으려면 라이브러리 수집 창의
URL 입력칸을 사용하세요.

## 설치

1. Chrome 주소창에 `chrome://extensions`를 입력합니다.
2. 오른쪽 위 `개발자 모드`를 켭니다.
3. `압축해제된 확장 프로그램을 로드합니다`를 누르고 이 `chrome_extension` 폴더를 선택합니다.
4. 확장 프로그램을 Chrome 도구 모음에 고정합니다.

이미 설치했다면 `chrome://extensions`의 이 확장 프로그램에서
**새로고침**을 눌러 버전 `1.1.0`을 적용하세요.

이 확장 프로그램은 팝업을 열 때 현재 탭의 주소를 읽고, 직접 입력한 링크는
버튼을 누를 때만 사용합니다.
라이브러리 계정 정보는 읽거나 저장하지 않습니다. 같은 PC의
`http://127.0.0.1:8765/`로 새 탭을 열며, PC 서버가 실행 중이어야 합니다.
