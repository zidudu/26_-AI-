# V8 beta.2 (8.0.4-beta.2) — Performance

## 2026-10-01 공유 패키지

- 자동 시작 서버가 정상 응답하면 BAT 재실행 시 기존 서버 재사용 및 브라우저 열기.
- URL 입력의 Enter 제출 / Shift+Enter 줄바꿈.
- 자료 목록·상세 사이 너비 조절과 넓어진 목록의 여러 열 표시.
- 왼쪽 사이드바 접기, 가용 UI 크기에 맞춘 플레이어 표시.
- Chrome 확장의 현재 탭 전송과 직접 링크 입력, 읽기 전용 AI MCP 연결 소스 포함.
- 새 PC용 설치 안내와 파일별 해시 목록 추가. 개인 설정·DB·미디어·가상환경 제외.

- 목록20개 compact API와 offset 페이지네이션, 파일/태그 일괄 조회로 N+1 제거.
- 첫 자료 자동 선택 제거, 명시 재생, preload=none, 자막/metadata 지연 로딩.
- 로그인/태그 기능을 유지하고 작업 요약 SSE + 제한된 실패 시 폴링 도입.
- 상세 작업 로그는 버튼 클릭 시만 요청. 숨긴 탭의 상태 연결 종료.
- 320×180 이하 JPEG 썸네일 캐시와 인증 우선 ETag/304.
- 720p/480p H.264/AAC + faststart + VBV 제한 모바일본. 별도 저장/원본 보존.
- 원본 fingerprint 기반 모바일본 재사용 및 stale 방지, 새 수집 후 선택적 자동 생성.
- 현재 로드된 자료 중 최대20개 순차 변환, 재생본/원본 용량별 다운로드 구분.
- 재생 중 상태 업데이트가 플레이어 src를 교체하지 않도록 수정.
- 선택형 Tailscale Serve8443 도우미: Funnel443 백업/보존 확인, origin 및 쿠키 분리.
- 기존02번은 Funnel443이 있으면 중단, 설정 GUI 저장 시 fast_url 유지.
- 모바일 고정 헤더에 제목이 가리지 않도록 스크롤 여백 조정, 파일 상세는 모바일 기본 접힘.

# V8 beta.1 (8.0.3-beta.1)

- 비밀번호 최소 길이를 8자로 조정. scrypt 해시 저장 방식은 유지.
- 로그인 화면에 `이 기기에서 자동 로그인` 추가. 선택 시 30일 장기 세션.
- 자동 로그인 세션은 브라우저 종료 후에도 유지되며 일반 세션의 비활성 타임아웃을 적용하지 않음.
- 로그아웃/모든 기기 로그아웃으로 장기 세션 즉시 폐기.
- 기존 V8 beta 보안 DB의 sessions 테이블은 시작 시 `remembered` 컬럼을 자동 마이그레이션.

# V8 beta (8.0.2-beta)

V8_alpha에서 유지: 라이브러리 GUI, 모바일 화면, 추출/재생/자막/태그/즐겨찾기, 기존 자료 import, worker 큐.

추가/수정:
- PIN/localhost 무인증을 제거하고 단일 소유자 로그인으로 통일.
- 영상/음원/TXT 파일 요청에도 인증, Origin/CSRF 확인, 세션 만료/철회.
- Tailscale Serve 개인 HTTPS 설정 도우미. 선택형 Cloudflare는 관리 전용으로 제한.
- 로컬 설정 GUI, 비밀번호 재설정, Windows 설정 폴더 권한 제한.
- 기존 DB 백업 방식 복사 및 WAL 체크포인트 처리.
- 고정 localhost 포트/단일 beta 인스턴스 잠금, 정상 종료 요청 파일.
- Windows 작업 스케줄러 자동 시작/정지/등록 해제 도우미 및 회전 로그.
- 비대화형 실행/원격 접속 시 Windows OS 동작 숨김과 서버 측 거부.
- Windows 자식 프로세스 Job 수명 제어.
- 연결 상태, 로그아웃, 모든 기기 로그아웃 UI.

외부 계정 설치/등록 및 실제 Windows 실행은 이 환경에서 완료한 배포가 아닙니다.
