# V8 beta.2 보안 / 공개·개인 경로

## 사용 목적

개인 PC의 단일 소유자 미디어 라이브러리입니다. 회원가입·불특정 다수용 서비스가 아닙니다.
기존 공개 Funnel 443 사용을 유지할 수 있으며, 8443은 Tailscale 내부 Serve 경로로 추가합니다.
Funnel의 공개 여부와 상관없이 이 앱은 localhost/HTTPS 모두 인증을 요구합니다.
정식 침투 테스트나 실제 Windows/Tailscale 운영 보안 검증을 완료한 제품은 아닙니다.

## 요청 경계

Uvicorn은 loopback에만 바인딩하고 `proxy_headers=False`를 사용합니다.
실제 peer가 loopback이고 Host가 설정에 정확히 등록된 origin이어야 합니다.
localhost Host에 프록시 전달 헤더가 있으면 OS 전용 요청으로 오인하지 않도록 거부합니다.
헤더에 적힌 임의 IP나 Tailscale 사용자 이름만으로 인증하지 않습니다.

외부 주소는 HTTPS이며, 추가 `fast_url`은 .ts.net의 명시적인 :8443만 받습니다.
443과8443은 origin이 다르고 쿠키 이름도 다릅니다. 쿠키가 포트별 저장되지 않는 특성 때문에
하나의 __Host 쿠키를 공유하지 않도록 분리했습니다. 두 경로는 동일한 라이브러리 DB와 계정입니다.

모든 API/원문/thumbnail/Range/HEAD/media/작업 이벤트 요청은 인증 대상입니다.
상태 확인용 최소 응답은 경로나 비밀을 노출하지 않습니다. 변경 요청은 Origin/CSRF 토큰을 검사합니다.
변경 가능한 임의 경로/API 파일 ID 입력은 서버의 등록된 파일 조회를 거칩니다.
원격에서는 OS 실행/폴더 선택/임의 로컬 폴더 등록을 허용하지 않습니다.
Cloudflare 관리 origin은 원본/음원/모바일본/이전재생본 또는 5MB 초과 파일을 거부합니다.

## 계정 및 세션

scrypt + 개별 salt, 상수 시간 해시 비교, 임의 세션 토큰, 서버에는 SHA-256 digest 저장을 유지합니다.
비밀번호 정책은8~128자이며, 짧고 예측 가능한 비밀번호가 충분히 강하다는 의미가 아닙니다.
외부 쿠키는 Secure/HttpOnly/SameSite=Strict/Path=/ 및 __Host 이름을 사용합니다.
로컬 HTTP와 개인8443은 각자 별도 쿠키를 씁니다.

일반 로그인은 최대12시간/비활성60분, 기억하기 선택은30일 절대 만료입니다.
비밀번호 재설정/모든 기기 로그아웃은 서버 세션을 무효화합니다.
로그인 시도는5분당8회 전체 제한, 동시 처리2건입니다. 원격 IP 헤더를 신뢰해 제한을 회피시키지 않습니다.
이 제한은 계정 서비스의 강력한 DDoS 방어가 아니며, 제3자가 로그인 한도를 소모할 수도 있습니다.

## 성능 변경이 보안에 미치는 영향

목록, 텍스트, 상태 요약, 작은 썸네일과 정적 UI는 인증 후 private 재검증 캐시를 사용합니다.
ETag/304 처리 전에 인증하므로 로그아웃 후 조건부 요청으로 접근할 수 없습니다.
로그인/부트스트랩/원본 미디어는 no-store이며 공유 캐시나 public 캐시를 사용하지 않습니다.
캐시/CDN에서 Cache Everything 같은 외부 강제 규칙을 추가하지 마세요.

SSE는 인증된 same-origin 세션으로만 열리고8개 연결 상한을 둡니다.
큐는 연결당 최신 스냅샷 하나, 상세 로그/큰 결과는 이벤트에 포함하지 않습니다.
heartbeat는 일반 로그인 비활성 시간을 갱신하지 않으며 주기적으로 세션을 재검증합니다.
큐에서 받은 데이터를 보내기 직전에도 유효성을 확인합니다. 세션 만료/철회 시 auth_expired 후 종료합니다.

미디어는 파일 ID로만 제공하고 원본 파일은 변경하지 않습니다.
새 모바일본은 별도 data/mobile_previews에 임시 생성/검증 후 원자 교체합니다.
원본 크기/수정 시각이 달라진 파생 파일은 제공을 거부하고 재생성하도록 합니다.
썸네일 생성은 허용된 등록 이미지에만 수행하고 이미지 크기 한도/디코더의 bomb 방어를 유지합니다.

## 비밀 / 실행 권한 / 한계

config의 owner.json, security.sqlite3, server.json, tunnel.token, runtime 설정을 채팅이나 공개 저장소에 올리지 마세요.
배포 ZIP은 config/data/output/.venv/logs 및 외부 바이너리·폰트를 포함하지 않습니다.
기존 설정 도구의 Windows ACL, 제한 사용자 자동 시작, 작업 자식 프로세스 종료 처리를 유지합니다.
FFmpeg는 쉘 문자열이 아니라 인수 배열로 실행하고 바이너리 로그를 안전하게 디코딩합니다.

이미 전송한 바이트를 로그아웃으로 회수할 수 없으며 열린 대용량 HTTP 응답은 시작 시 인증합니다.
로그아웃은 진행 중인 원본 다운로드를 강제로 끊는 기능이 아닙니다. 이후의 새 요청은 거부됩니다.

로컬 관리자 악성코드, 계정 탈취, 외부 엔진/OS의 미발견 취약점, 악성 미디어 처리 위험까지 방어한다고 주장하지 않습니다.
최소 권한으로 실행하고, 외부 엔진/OS를 업데이트하며, 정기적으로 설정/DB/원본을 백업하세요.
05번 도우미는 443 변경을 검증하지만 Windows/실사용 Tailscale에서의 실동작은 별도 확인이 필요합니다.
