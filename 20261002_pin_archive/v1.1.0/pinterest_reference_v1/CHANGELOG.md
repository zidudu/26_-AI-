# 1.1.0

- Pinterest 보드별 자동 반복 수집, 수동 실행, 일시중지·재개와 서버 재시작 후 미완료 상태 복구를 추가했습니다.
- 목록 탐색, 핀 상세 정보 수집, 이미지 다운로드를 별도 상태로 기록하고 상세 정보 변경 이력을 보존합니다.
- 상세·이미지 실패에 지수 간격 재시도와 수동 오류 재등록을 추가했습니다.
- 반복 수집용 Chrome은 로그인한 전용 프로필을 이용해 창을 띄우지 않고 실행합니다.
- 스토리 핀에서 실제 표시된 이미지도 수집하도록 상세 화면 선택자를 보완했습니다.

# 1.0.1
- Fixed startup failure when port 8765 is already in use. The launcher now automatically tries the next available localhost port (up to 50 ports).
- 선택 포트를 `data/runtime.json`에 기록하고 MCP·크롤러 가져오기 예제가 서버 식별값을 확인한 뒤 자동 연결하도록 수정했습니다.
- 포트 선택 시 소켓을 계속 보유해 선택과 서버 시작 사이의 포트 선점 가능성을 줄였습니다.
- 앱·API·MCP·화면의 버전을 1.0.1로 통일했습니다.

# 변경 내역

## 1.0.0 — 2026-10-02

- 첨부 정적 갤러리를 로컬 서버·SQLite·원본 파일 저장 기반의 이미지 라이브러리로 확장했습니다.
- 파일/폴더/직접 URL/기존 크롤러 manifest 가져오기와 출처 메타데이터 보존을 추가했습니다.
- 정확한 이미지 중복 병합, 한글·영문 키워드 검색, 보드·즐겨찾기·선택 내보내기를 추가했습니다.
- Pinterest 전용 프로필 로그인과 허용된 공개 페이지의 화면 수집 어댑터를 분리했습니다.
- 선택형 OpenAI/Ollama 비전 태그 및 검색 후보 재정렬을 구현했습니다.
- 선택형 CLIP 다국어 의미 검색, SQLite 벡터 저장 및 RRF 하이브리드를 구현했습니다.
- AI가 검색 후 실제 썸네일을 읽는 읽기 전용 stdio MCP 도구 5개를 추가했습니다.
- 작업 진행/중단/재시도/부분 실패와 재실행 중복 병합을 추가했습니다.
- 기본 API 접근 제한, 파일 검증, 다운로드 사설망 차단, 비밀 키 비저장을 적용했습니다.
- 데스크톱/모바일 UI와 한국어 설치·연동·검증 문서를 포함했습니다.

실제 외부 연동 검증 범위는 `docs/VALIDATION.md`를 참고하세요. 공개 서버 및 단일 EXE는 포함하지 않습니다.
