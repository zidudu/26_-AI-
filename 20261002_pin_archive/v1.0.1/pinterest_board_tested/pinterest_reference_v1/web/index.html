AI 이미지 분석

분석을 실행할 때만 이미지를 선택한 공급자에게 전송합니다. OpenAI는 별도 API 비용이 발생하며, Ollama는 이 PC에서 실행됩니다.

키 발급은 OpenAI 보안 설정 흐름을 사용하세요. 비밀 키를 대화에 붙여 넣지 마세요.

연결: http://127.0.0.1:11434 · 모델 설치와 실행은 자동으로 하지 않습니다.

로컬 의미 검색

이미지와 한국어 문장을 CLIP 벡터로 비교합니다. 04_install_semantic.bat 실행 후 색인을 만드세요. 최초 색인 시 모델을 다운로드하며, 이미지 자체는 외부로 전송하지 않습니다.

CPU 실행 · 벡터는 SQLite, 모델은 data/models에 저장합니다. 하이브리드는 키워드와 벡터 검색 순위를 합칩니다.

AI 검색 도구 연결

읽기 전용 MCP

search_images로 검색하고 get_image로 실제 이미지 썸네일을 읽습니다. 연결만으로 삭제·수집 권한이 생기지 않습니다.

위 설정은 로컬 stdio MCP 클라이언트용입니다. ChatGPT 웹은 localhost에 직접 연결하지 않으므로 지원되는 Secure MCP Tunnel 또는 별도의 원격 MCP 설정이 필요합니다. 이 프로그램은 자동으로 서버를 공개하지 않습니다.

첫 사용 순서
  1. 이미지 가져오기
    파일·폴더, 직접 이미지 URL, 기존 크롤러의 JSON을 가져오세요.
  2. 태그와 보드 정리
    상세 화면에서 제목·태그·출처를 편집합니다. 파일명 대신 기록된 내용으로 검색할 수 있습니다.
  3. 검색해서 꺼내 쓰기
    키워드 검색은 바로 사용할 수 있습니다. AI 태그, 의미 검색, MCP는 필요할 때 추가하세요.
Pinterest 수집
03_install_browser.bat을 실행하거나 설정에서 Chrome/Edge를 선택하세요. Chrome/Edge에서는 로그인 창을 열어 직접 로그인한 뒤 창을 닫으세요. Playwright Chromium에서는 작업 기록의 로그인 완료를 누르세요. 보드 URL을 입력하면 해당 핀의 상세 화면에 표시된 이미지로 수집을 시도합니다.
자동 접근에는 Pinterest의 사전 허가가 필요합니다. 허용된 범위에서만 수집하세요. 로그인·CAPTCHA·차단을 우회하지 않으며 화면에 실제 제공된 이미지 URL만 사용합니다.
Pin 링크는 원저작자 사이트나 이용 허가를 의미하지 않습니다. 원본 출처를 확인하지 못하면 비워 둡니다.

샘플과 실제 데이터
처음 보이는 24장은 첨부된 갤러리 ZIP의 샘플입니다. 실제 Pinterest 수집 결과나 AI 분석 결과가 아닙니다. 출처 필터에서 샘플을 구분할 수 있습니다.
샘플은 처음 한 번만 등록됩니다. 삭제한 샘플을 재실행 시 복구하지 않습니다. 원본 이미지와 GIF 애니메이션은 보존하되, 썸네일·AI 분석·색인은 첫 프레임을 사용합니다.
기존 크롤러와 연결
examples/import_from_crawler.py는 이미지 파일·URL과 메타데이터를 함께 가져오는 예제입니다. 새 수집기를 붙일 때 DB나 검색기는 바꿀 필요가 없습니다.
선택한 이미지를 내보내면 원본 파일과 JSON 메타데이터가 함께 담깁니다. 내보내기는 저작권이나 재사용 허가를 부여하지 않습니다.
실행 방법·제한·테스트 내역은 패키지의 README.md와 docs 폴더에서 확인하세요.
