# 타사 자료와 권리

이 프로그램은 Pinterest 공식 제품이 아니며 Pinterest와 제휴하거나 공식 인증받았다고 표시하지 않습니다.

`seed/images/`의 24개 사진은 사용자가 첨부한 `pinterest_site.zip`의 자료입니다. `seed/credits.json`은 첨부 자료의 출처 기록을 보존한 것입니다. `seed/manifest.json`에는 제목별로 대응되는 출처와 작성자를 연결했습니다. 첨부 자료에 Unsplash License라고 적혀 있어도 이 프로그램이 독립적으로 모든 권리나 현재 이용 조건을 검증한 것은 아닙니다. 실제 재배포·게임 자산·상업적 사용 전 원본 출처와 이용 조건을 확인하세요. 이미지에 등장하는 대상에 관한 별도 권리가 있을 수 있습니다.

새로 수집하는 이미지도 동일하게 사용 권한을 자동 취득하지 않습니다. 제목·태그·메타데이터 분석과 파일 보관은 해당 이미지를 배포할 권리를 부여하지 않습니다.

Python 라이브러리와 선택형 모델에는 각 배포자의 라이선스가 적용됩니다. 패키지는 requirements 파일로 설치하며 모델 가중치는 이 ZIP에 포함하지 않습니다. 시스템 글꼴을 사용하고 별도 글꼴 파일은 배포하지 않습니다.

이 배포물의 새 애플리케이션 코드는 사용자에게 검토·수정·실행 가능한 형태로 제공됩니다. 타사 이미지·라이브러리·모델에 대한 권리를 새로 부여하지 않으며 외부 서비스의 규칙을 대신하지 않습니다.
