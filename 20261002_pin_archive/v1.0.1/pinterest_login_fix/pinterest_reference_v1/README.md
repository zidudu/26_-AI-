# Pin Archive 1.0.1

**이미지를 모으고, 키워드로 찾고, AI가 실제 이미지를 꺼내 읽을 수 있는 개인용 시각 레퍼런스 라이브러리입니다.**

첨부된 `pinterest_site.zip`의 Pinterest형 갤러리와 24개 샘플을 출발점으로, Python 백엔드와 SQLite 영구 저장소를 추가했습니다. 이 ZIP은 실행 스크립트와 전체 소스 코드가 포함된 배포본이며, Python이 포함된 단일 EXE는 아닙니다. 원본 첨부 ZIP에는 크롤러 소스가 없었으므로 기존 크롤러에 직접 덮어쓰는 대신 파일·JSON·HTTP로 연동하도록 만들었습니다.

## 1. 바로 실행하기 — Windows

1. 압축을 **모두 해제**합니다. 예: `D:\PinArchive\pinterest_reference_v1`. ZIP 내부에서 BAT를 바로 실행하지 마세요.
2. 처음 한 번 `01_setup.bat`을 실행합니다. 가상환경 생성, 필수 패키지 설치, 오프라인 회귀 검사를 진행합니다.
3. `02_start.bat`을 실행합니다. 브라우저에서 로컬 라이브러리가 열립니다. 이후에는 이 파일로 시작하면 됩니다.

Python **3.13 64비트**에서 코드를 검증했습니다. 설치 스크립트는 Python 3.11~3.14를 허용하지만 이 범위의 모든 버전·Windows 조합에서 실행 검증한 것은 아닙니다. Python과 pip 인터넷 연결이 필요합니다. 기본 갤러리·키워드 검색에는 OpenAI 키나 Ollama가 필요 없습니다.

기본 주소는 `http://127.0.0.1:8765`입니다. 이미 사용 중이면 8766부터 최대 50개 포트 중 빈 포트를 자동 선택하고 실행 창에 실제 주소를 표시합니다. 선택된 주소는 `data/runtime.json`에 기록되어 MCP와 가져오기 예제가 자동으로 찾습니다. 실행 창은 서버이므로 닫으면 앱이 종료됩니다. 브라우저만 닫으면 서버는 계속 실행됩니다. 종료하려면 실행 창에서 `Ctrl+C`를 누르세요.

특정 포트부터 검색하려면 다음처럼 실행합니다.

```bat
02_start.bat --port 8766
```

한 데이터 폴더를 사용하는 서버를 여러 개 동시에 실행하지 마세요. 앱 폴더를 옮길 때는 서버를 종료하고, 새 위치에서 `.venv`를 지운 뒤 `01_setup.bat`을 다시 실행하세요. `data` 폴더는 삭제하지 않습니다.

### macOS / Linux

```bash
bash setup.sh
bash start.sh
```

헤드리스 환경에서는 기본 갤러리/API는 사용할 수 있지만 Pinterest 수집기는 화면이 있는 브라우저 세션이 필요합니다. 모바일 크기 UI를 제공하지만 휴대전화에 Python 서버를 설치하거나 LAN으로 공개하는 기능은 포함하지 않습니다.

## 2. 포함된 기능

| 영역 | 1.0 동작 |
|---|---|
| 이미지 라이브러리 | 원본 이미지와 별도 WebP 썸네일, 제목·설명·태그·출처·작성자·권리 메모 저장 |
| 가져오기 | 이미지 파일/폴더, 직접 이미지 URL, 기존 크롤러 JSON, CLI 파일/메타데이터 연동 |
| 중복 처리 | 파일 SHA-256 및 디코딩한 RGBA 픽셀 비교. 재수집 키워드·태그·출처 이력 병합 |
| 키워드 검색 | 한글·영문, 제목/태그/카테고리/설명/수집 키워드, 부분 일치와 SQLite FTS5 |
| 정리 | 즐겨찾기, 여러 보드에 같은 이미지 등록, 출처·카테고리·미분석 필터 |
| Pinterest | 전용 프로필 수동 로그인, 키워드/보드 URL의 화면 기반 수집, 진행/중단/재시도 |
| AI 태깅 | 선택형 OpenAI API 또는 로컬 Ollama, 태그/설명/색상/구도 분석 |
| 의미 검색 | 선택형 CLIP 이미지 임베딩 + 다국어 텍스트 임베딩, SQLite 벡터 저장 |
| 하이브리드 | 키워드와 벡터 검색의 순위를 RRF로 합산. 미설치 시 명시적으로 키워드로 전환 |

| 내보내기 | 선택 이미지 원본과 메타데이터 JSON을 ZIP으로 저장 |
| 상태 기록 | 대기/실행/완료/일부 실패/실패/중단/이전 실행 종료를 구분 |

수집, AI 태그 생성, 의미 검색 색인은 **단계별로 직접 실행**합니다. 수집만 눌렀다고 외부 AI를 호출하거나 요금을 발생시키지 않습니다. 자동 예약 수집·정기 스케줄러는 1.0에 포함하지 않습니다.

## 3. 처음에는 이렇게 사용하세요

`가져오기`에서 파일 몇 장을 선택하고 공통 태그를 입력합니다. 상세 화면에서 제목·출처를 확인하고, 보드에 모읍니다. 검색창에 `게임 UI`, `파란색`, `lobby`처럼 기록된 단어를 넣으면 검색됩니다.

키워드 검색은 입력 단어를 **OR 방식**으로 후보 검색하고 제목·태그 일치에 가중치를 줍니다. 아직 태그가 없는 이미지를 긴 자연어만으로 정확히 찾는 기능은 아닙니다. 긴 자연어 검색은 의미 검색 모듈을 설치하거나 AI 태그를 먼저 생성하세요. 검색 점수는 확률·정확도 백분율이 아닙니다.

상단 `선택` → 이미지 선택 → `내보내기`를 누르면 원본과 `manifest.json`이 함께 저장됩니다. 내보낸 ZIP을 풀고 CLI 예제로 다시 가져올 수도 있습니다. 이는 선택 이미지의 파일·수동 메타데이터 이관이며, 전체 설정·작업 이력·벡터·AI 결과의 완전 복원은 아닙니다. 완전 백업은 종료 후 `data` 폴더를 복사하세요.

처음 보이는 24장은 첨부된 갤러리의 샘플입니다. **실제 Pinterest 수집 결과나 AI 분석 결과가 아닙니다.** 원본 `credits.json`과 제목이 일치하는 출처·작성자 정보는 보존했습니다. 샘플은 첫 실행에만 등록되며, 삭제한 샘플을 매번 되살리지 않습니다.

## 4. Pinterest 수집

`03_install_browser.bat`으로 수집용 Chromium을 설치하거나, 앱 설정에서 이 PC의 Chrome/Edge를 선택합니다. 기존 사용자의 일반 Chrome 프로필을 가져오지 않고 `data/pinterest_profile`을 따로 사용합니다.

`Pinterest 수집` → `로그인 창 열기` → 열린 브라우저에서 직접 로그인 순서입니다. 설정에서 Chrome/Edge를 선택한 Windows 환경에서는 일반 브라우저 창이 열리며, 로그인 후 그 창을 닫으면 전용 프로필에 세션이 저장됩니다. Chromium을 선택한 경우에는 앱의 `작업 기록`에서 `로그인 완료`를 누르세요. 이후 키워드 또는 지원되는 전체 Pinterest 보드/핀 HTTPS URL을 입력하고 확인할 핀 수와 보드를 지정합니다. 로그인 창 작업의 완료 표시는 실제 계정 접속이나 수집 성공을 보증하지 않습니다.

Pinterest 이용약관은 자동화된 접근·스크래핑에 사전 허가를 요구합니다. [공식 약관](https://policy.pinterest.com/en/terms-of-service)을 확인하고, 권한이 있는 범위에서만 사용하세요. 확인 체크박스 자체가 Pinterest의 허가를 대신하지는 않습니다.

수집기는 화면에 제공된 `img`, `srcset`, Pin 링크만 읽습니다. CAPTCHA 해결, 프록시 회전, 차단 우회, 비공개 글 접근, 숨은 내부 API 호출은 없습니다. 제한 화면·HTTP 401/403/429를 만나면 중단합니다. 수량은 **확인 상한**이며 신규 이미지 수를 보장하지 않습니다. 사이트 화면 구조 변경, 계정 권한, 네트워크 환경에 따라 수집 어댑터의 수정이 필요할 수 있습니다.

Pin URL은 원저작자 사이트나 사용 허가를 의미하지 않습니다. 확인하지 못한 원본 출처 URL은 비워 두며, 상세 화면에서 직접 보완할 수 있습니다.

## 5. AI 태그와 의미 검색

### OpenAI / Ollama

설정에서 공급자를 선택합니다. OpenAI는 이미지 입력 및 구조화 응답을 지원하는 모델 이름과 API 인증을 사용합니다. 기본 모델명은 `gpt-4.1-mini`이고 직접 변경할 수 있습니다. 계정에서의 실제 모델 이용 가능 여부는 별도 확인이 필요합니다.

키는 로컬 앱 설정의 비밀번호 필드에 입력하거나 이미 안전하게 구성된 `OPENAI_API_KEY` 환경변수를 사용합니다. 대화나 소스 파일에 키를 붙여 넣지 마세요. 입력한 키는 현재 Python 프로세스 메모리에만 남고 브라우저 저장소·DB·응답·작업 로그에는 저장하지 않습니다. 서버를 재시작하면 다시 입력해야 합니다. 메모리 키 지우기는 운영체제 환경변수의 키를 지우지는 않습니다.

OpenAI API는 [ChatGPT 구독과 별도 과금](https://help.openai.com/en/articles/9039756-billing-settings-in-chatgpt-vs-platform)입니다. API 대신 Ollama를 사용하려면 이 PC에서 Ollama를 실행하고 이미지 입력을 지원하는 모델을 직접 설치해야 합니다. 앱은 `http://127.0.0.1:11434`에만 연결합니다. 모델 목록은 불러올 수 있지만 설치·시작은 자동으로 하지 않습니다.

AI 분석 버튼을 누르면 이미지 전송과 비용 안내를 확인합니다. 분석 결과는 `ai_tags`/`ai_description`에 분리하며 수동 제목·태그를 덮어쓰지 않습니다. 결과는 **검토 필요** 상태입니다. 그림만 보고 저작권·원작자·AI 생성 여부를 확정하도록 요청하지 않습니다.

### CLIP 의미 검색

앱을 종료하고 `04_install_semantic.bat`을 실행한 다음 앱 설정에서 `색인 만들기`를 누릅니다. PyTorch 관련 패키지와 최초 모델 다운로드에 추가 디스크·메모리·인터넷이 필요합니다. 기본 구현은 CPU 실행입니다.

이미지는 `sentence-transformers/clip-ViT-B-32`, 검색 문장은 이에 정렬된 `sentence-transformers/clip-ViT-B-32-multilingual-v1`을 사용합니다. 이미지 자체를 외부 모델 서버에 전송하지 않고 로컬에서 계산합니다. 모델 다운로드는 외부 통신입니다. 새 이미지가 추가되면 다시 미색인 이미지 색인을 만드세요.

의미 검색 미설치/미색인 상태를 성공으로 가장하지 않습니다. `의미 검색`은 명시적인 오류를 보여주고, `하이브리드`는 키워드 검색만 사용했다는 경고를 표시합니다. 상세 화면의 `밝기 패턴이 비슷한 이미지`는 dHash 기반으로, 의미 검색이나 정확한 중복 판정이 아닙니다.

## 6. AI가 라이브러리를 검색하고 이미지를 읽기

`05_mcp_config.bat` 또는 앱 설정의 MCP 구성에서 실제 설치 경로가 담긴 설정을 확인합니다. 이를 **stdio MCP를 지원하는 로컬 AI 클라이언트**에 등록하고 Pin Archive 서버를 실행해 두세요. MCP는 시작할 때 `data/runtime.json`과 서버의 식별값을 확인하므로 포트가 바뀌어도 설정을 다시 만들 필요가 없습니다. 별도 데이터 폴더로 실행했다면 `05_mcp_config.bat --data-dir "D:\\PinArchiveData"`처럼 같은 경로를 지정하세요.

제공 도구는 `search_images`, `show_images`, `get_image`, `get_image_metadata`, `list_collections`, `library_status`입니다. `show_images`는 한 번에 최대 6장의 실제 WebP 썸네일을 반환하며, MCP 앱 화면을 지원하는 ChatGPT에서는 갤러리 카드로 표시합니다. 전부 읽기 전용이며 이미지 삭제·Pinterest 수집·비밀 키 읽기를 노출하지 않습니다.

```text
사용자: 파란색 게임 로비 레퍼런스 찾아줘.
AI → search_images(query="파란색 게임 로비", mode="keyword", limit=6)
검색 결과 → 이미지 ID, 태그, 설명, 출처
AI → get_image(pin_id="검색으로 반환된 32자리 ID")
반환 → 실제 WebP 이미지 썸네일 + 원본 크기와 메타데이터
```

검색만 호출해서는 이미지 픽셀을 본 것이 아닙니다. 실제 시각 판단에는 `get_image` 호출이 필요합니다. 썸네일은 최대 700×1000이며 원본은 라이브러리에 보존됩니다.

**이 ZIP을 실행하는 것만으로 현재 ChatGPT 대화가 연결되지는 않습니다.** ChatGPT 웹은 localhost를 직접 읽지 않으므로, 지원되는 [Secure MCP Tunnel 또는 원격 MCP 연결](https://help.openai.com/en/articles/12584461-developer-mode-and-mcp-apps-in-chatgpt-beta)과 별도 구성이 필요합니다. 이 버전은 stdio 브리지를 제공하며 원격 HTTP MCP 서버·인증·터널 설치·계정 연결은 수행하지 않습니다. 웹 서버를 그대로 인터넷에 노출하지 마세요.

## 7. 기존 크롤러 연동

기존 크롤러를 변경하지 않고 결과 파일을 가져오는 방식을 제공합니다. 자세한 필드와 HTTP 호출은 `docs/INTEGRATION.md`에 있습니다.

```bat
.venv\Scripts\python.exe examples\import_from_crawler.py D:\MyCrawler\manifest.json
```

`examples/crawler_manifest.json`을 참고하세요. 각 항목에 상대 `file` 또는 `image` 경로와 제목·태그·수집 키워드를 넣습니다. 경로가 manifest 폴더 밖으로 나가면 차단합니다.

직접 이미지 URL 목록은 다음처럼 권한 확인 후 작업으로 등록합니다.

```bat
.venv\Scripts\python.exe examples\import_from_crawler.py D:\MyCrawler\urls.json --urls --authorized
```

작업 등록은 완료와 다릅니다. 결과는 앱의 작업 기록에서 신규·중복·실패 건수를 확인하세요.

## 8. 데이터·보안·범위

`data/library.sqlite3`는 메타데이터, `data/images`는 원본, `data/thumbnails`는 미리보기, `data/models`는 선택형 모델, `data/pinterest_profile`은 로그인 프로필입니다. `data` 폴더에는 개인 이미지와 세션 정보가 있으므로 배포 ZIP에 넣지 마세요.

로컬 바인딩, 호스트 검증, 변경 요청 토큰, Origin 검증, 이미지 파일 검증, 다운로드 대상 사설망 차단 및 리디렉션 재검증을 넣었습니다. 다중 사용자 인증·권한 분리·보안 감사가 완료된 서비스는 아닙니다. 운영체제의 같은 사용자 권한을 가진 프로그램으로부터 보호하는 비밀 저장소도 아닙니다.

파일당 20 MB, 한 번에 50개 파일/100 MB, URL 작업 100개, Pinterest 확인 상한 500개, 내보내기 200 MB, 대기 작업 20개로 제한합니다. 40메가픽셀 이하 이미지만 지원합니다. SVG는 받지 않습니다. GIF/애니메이션 원본은 유지하되 미리보기·AI·벡터에는 첫 프레임을 사용합니다. 애니메이션은 첫 프레임이 같다는 이유만으로 병합하지 않습니다.

SQLite 벡터 선형 검색과 전체 후보 로딩을 사용하는 개인용 1.0 구현입니다. 수십만 장 규모의 성능·ANN 색인, 배포 서버, 자동 예약, 공유 계정, OAuth 및 Windows 설치 프로그램은 포함하지 않습니다.

## 9. 검증과 문서

`06_test.bat`으로 현재 92개 오프라인 회귀 검사를 다시 실행할 수 있습니다. 외부 로그인이나 유료 AI 호출을 하지 않습니다.

1.0.1 안정화 점검에서 Windows `01_setup.bat` 실행과 회귀 검사 88개 통과, 8765·8766 포트 점유 상태에서 `02_start.bat`의 8767 자동 기동, 실제 Edge의 데스크톱·모바일 localhost 화면, MCP 검색·WebP 이미지 반환, 크롤러 예제의 신규·중복 가져오기를 확인했습니다. 이후 ChatGPT 갤러리와 Windows 일반 Chrome 로그인 경로를 추가하여 현재 회귀 검사 92개가 통과했습니다. 전용 프로필에 Pinterest 로그인 세션이 저장된 것은 사용자 확인과 세션 쿠키로 확인했으나, **실제 로그인된 Pinterest 수집, 실제 OpenAI/Ollama 추론, CLIP 모델 다운로드·추론은 아직 검증하지 않았습니다.** 기존 1.0.0 릴리스에서 보고된 UI 23개·통합 13개 검사는 당시 기록이며 이번에 모두 재실행한 결과는 아닙니다. 상세 범위는 `docs/VALIDATION.md`에 적었습니다.
